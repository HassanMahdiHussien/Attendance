# Implementation Plan: OCR-First Internal Regulations

**Branch**: `031-ocr-first-regulations` (based on 030) | **Spec**: [spec.md](spec.md)

## Existing pipeline (read first)
`RenderLegalPages` renders pages and dispatches `ReadLegalPageText` (text layer via `TextLayerProbe`, else Tesseract via `PdfPages::ocr`) and, per 030, `ReadLegalPageWithAi` (mode `now`) or `SubmitLegalReadingBatch` (mode `batch`); the reconcile command in `routes/console.php` re-dispatches pending pages. `UnitBuilder` compares reading A (`text`) with reading B (`ai_text`) per article. Regulations: `RegulationUpload`, `RegulationApprovals`, `app/Filament/Admin/Pages/InternalRegulation.php` + its Blade view. Word/text sources are handled inside `RenderLegalPages` (`verified_text`).

## Design
- **OCR confidence:** `PdfPages::ocrWithConfidence(png): array{text, confidence}` runs `tesseract … tsv` once, rebuilds the text from the TSV words in line order (same `ara`, `--psm 6`), and returns the mean `conf` of words with conf ≥ 0. Keep `ocr()` behaviour for statutes or make it delegate. Migration: `legal_import_pages.ocr_confidence` decimal(5,2) nullable.
- **Decide after reading A:** AI reading for a page must not be queued until reading A finished for that page when the run is a regulation. Simplest: for regulation runs, `ReadLegalPageText` decides at the end — confident → `ai_status = skipped`; otherwise leaves `pending` and dispatches the AI reading itself (now mode) or lets the batch submission pick it up (batch submission only collects pages whose `text_status = done` and `ai_status = pending`; it waits until no regulation page has `text_status = pending`). Statute runs keep today's parallel dispatch. Reconcile must not dispatch AI for regulation pages still awaiting reading A.
- **Units:** `UnitBuilder` treats `skipped` as terminal; an article whose touched pages are all `skipped` gets status `verified_single`, `extraction_a` = text, `extraction_b` = null; otherwise existing logic (an article touching a skipped page and a read page compares using reading A for all pages and reading B where present — simplest correct option: if any touched page is not skipped, require AI reading on all touched pages, so mark those skipped pages' neighbours… → choose: for mixed articles, set status `mismatch` with reason `partial_single_reading` so a human resolves against the page images. Document in plan resolutions if Codex finds a cleaner option.)
- **Status:** add `VerifiedSingle`; update every verified-status list found by grep (`UnitCorrection`, `RegulationApprovals`, `UnitBuilder`, `LegalUnit` model guards/scopes, `LegalLibraryArchive` — statutes never contain it, so the archive should reject it), DB immutability triggers if they enumerate statuses (new migration recreating them), labels (`LegalLibraryLabels`), translations.
- **Approvals:** `approveAllVerified` excludes `verified_single`; individual `approve` allowed; audit `method`. Blade: label + page image link for single-reading units.
- **Config:** `displanery.legal_library.ocr_confidence_min` (env `LEGAL_OCR_CONFIDENCE_MIN`, 85); regulations default `reading_mode = now`.
- ADR `docs/adr/0011-single-reading-for-company-regulations.md` (+ README index), WEIRDNESS line.

## Tests
OCR confidence parsing from a TSV fixture; confident regulation page → `skipped`, no AI call (FakeClaudeClient asserts zero calls), units `verified_single`; low-confidence page → AI reading + comparison; mixed article handling; statute run unchanged (AI requested on every page); approve-all skips `verified_single`, individual approve works and is audited; not citable before approval, citable after; immutability of `verified_single`; translations, behaviour inventory, Pint, full suite.

## Plan review resolutions

- **Blocker — mixed articles:** A second reading missing on a skipped page cannot establish agreement for an article crossing that page. A mixed article remains a `mismatch` with `partial_single_reading`; the lawyer must resolve it against the source images, and only then approve the resulting `verified_human` version. Never mark it `verified_auto` from the partial comparison.
- **Blocker — skipped pages and replay:** A regulation's AI work starts only after its local page result is committed. Reconcile and batch submission must wait for local readings; a completed local page is classified before either can send it. Retried jobs must leave `skipped` untouched. An AI failure keeps the existing retry path; a local failure becomes reviewable as a mismatch, not a citable unit.
- **Blocker — status and immutability:** `verified_single` is limited to internal regulations, needs an import page and source image, and is immutable in both the model and MySQL triggers. It is citable only through the existing tenant-scoped regulation approval gate. Bulk approval excludes it. Corrections create versions and leave approval with the old version.
- **Should fix — independent outside readings:** A supplied secondary text or outside transcription follows the established two-reading path. OCR skipping applies only when no independent second source was supplied. Statutes retain their parallel two-reading flow.
- **Should fix — OCR confidence:** Average only valid TSV word rows with nonnegative confidence; an empty or malformed TSV gives no confidence and sends the page to AI. Preserve line breaks for article splitting. Clamp the configured threshold to 0–100 and default to 85.
- **Should fix — review visibility and counts:** Show the source page link beside each `verified_single` unit and label its individual approval clearly. Counts report local skipped pages separately from AI-read pages. The statute-only JSON archive continues to reject `verified_single`; its format and two-reading validation remain unchanged.
- **Decision under the supplied missing-context rule:** For a regulation page with a usable PDF text layer, skip AI without OCR. For OCR pages, use the configured mean word confidence. Keep the existing `claude-sonnet-5-5`/low defaults and regulation `now` mode.
