What you need: company setup completed, an employee and branch, and enough incident facts. You can start from **Open new case** or [Reports inbox](help:hr/reports-inbox).

![The new case form](shots/new-case)

1. Choose **Branch** and **Employee**. Select **Additional employees in this incident** if the same event involves others. Each employee gets a separate case within the incident.
2. Enter **Location** or **Place if not listed**, **Incident date and time**, **Violation type**, and **Incident description**. Add the **Alleged responsible person**, **Person responsible for follow-up**, and **Witnesses, separated by commas** when known.
3. Select **Save draft**. Answer any open intake questions on the draft case page. For an incident, write a separate **Description for this employee** before that employee's defense letter is drafted.
4. Select **Check for duplicates**. Review cases near the incident time, choose **Link the new case as a duplicate report** if appropriate, then select **Continue and open case**.

# Opening a case from a report

Select **Convert to case** on a report in **Reports inbox**. The screen shows the summary the reporter approved, with the conversation and attachments beside it.

1. Under **People involved**, match each name the reporter wrote to an employee: tap the right suggestion, use **Search by name or employee number**, or **Add a new employee**. One linked case opens per employee.
2. Check the case details. Under each field you see the reporter's own words. If the report gave a date but no time, leave **Incident time, if known** empty: the case records "time not stated".
3. Select **Open the case**. Duplicate and conflict-of-interest checks run automatically. If nothing is found, the case opens. If something is found, it is shown on the same screen and you choose to link it as a duplicate or open a separate case.

Good to know:

- Opening can be blocked by incomplete company setup, missing required facts, or no approved law effective for the branch.
- The case page may show **Prior record**, a repeat alleged responsible person, or a committee conflict. An employee-linked committee conflict requires a replacement; a name-only match needs HR verification with a reason.
- The duplicate review uses the incident time within 48 hours. A separate case remains possible after review.
