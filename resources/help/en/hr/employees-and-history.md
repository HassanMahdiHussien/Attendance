---
title: Find employees
summary: Use the employee list, page, and import.
audience: hr_staff
order: 130
---

Open **Employees** from the navigation.

1. Search the list by name, employee code, or department. Select an employee to open the employee page.
2. The page shows the employee's identity, branch, position, and hire date. Its **Attendance** section will show details in a later release.
3. Use **Import employees** on the list page for a CSV or XLSX file. Choose **Full active list** when every active employee is included, or **Partial update** for selected employees. Set the effective date.
4. Check the suggested column mapping. A sample appears only for a mapped column. The employee code is required; a full list also needs name and branch. Empty Arabic names use the English name.
5. Review new, changed, unchanged, missing and error counts before confirming. An unknown branch or duplicate code blocks the import. Missing employees enter exit review and stay active until HR confirms an exit date.
6. A file already imported cannot be committed again. After import, download its original file from the result link. Changes to employee fields appear on the employee page with their effective dates.

Employee records are limited to the company you can access.
