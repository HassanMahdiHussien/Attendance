---
title: Ask the Assistant
summary: Ask about attendance, request a report, and confirm employee changes the Assistant proposes.
audience: hr_staff
order: 180
---

Open **Assistant** and type a question in English or Arabic, for example "How is employee 23000065 doing this month?" or "How many absences in Hilla last week?". The Assistant reads the same figures as the dashboard, the employee page and the exports, so its answers match what you see on those screens. It looks up an employee by exact code first; if a name matches several people, it asks you which one you mean.

Each answer ends with a line written by the system, not by the AI, saying what actually happened: **Changes applied: none**, and how many proposals are waiting for you. Trust that line over the answer text. Tool activity under each answer lists what the Assistant looked up.

Ask for a report ("Give me the lateness report for October") and the Assistant requests one of the existing exports with the same filters as the screens. The download link appears in the conversation only when the file is ready, and only for you. You can also find it under **Exports**.

To change employee values, describe the change: "Set the end time of 23000065 to 18:00 from 1 November". The Assistant only **proposes** it. A card shows each employee, every field before and after, and the effective date. Nothing changes until you press **Confirm**. Changing only the end time never changes the start time, rest days or work pattern. Confirmed changes are recorded in the employee's history with the source **Chat**, and the affected days are recalculated. If someone changed those values after the proposal was made, Confirm refuses it as out of date; ask again. To undo a confirmed change, ask for a new change back to the old value.

Changes from chat are switched off for each company until an administrator turns on **Allow employee changes proposed by chat** under **Company settings**, with a reason. While it is off, the Assistant can still answer questions and make reports.

Your conversations are visible only to you. If AI is not configured, the page says so and earlier conversations stay readable.
